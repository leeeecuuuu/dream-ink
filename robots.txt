                        <h4>使用技巧</h4>

                        <p style="margin-top: 12px;"><strong>1. 接口与网络配置</strong></p>
                        <ul style="margin-bottom: 12px; padding-left: 20px;">
                            <li><strong>直连官方：</strong>Base URL 默认填写
                                <code>https://generativelanguage.googleapis.com</code>。请确保你的网络环境可以正常访问 Google 服务。
                            </li>
                            <li><strong>使用代理：</strong>如果你有自建的 API 代理，将 Base URL
                                替换为你的代理地址即可解决跨域和网络限制问题。</li>
                        </ul>

                        <p><strong>2. 提示词编写指南</strong></p>
                        <ul style="margin-bottom: 12px; padding-left: 20px;">
                            <li><strong>黄金公式：</strong>主体描述 + 环境背景 + 细节补充 + 光影效果 + 艺术风格。<br>
                                <span style="color: var(--text-muted); font-size: 0.85rem;">例如：一只戴着墨镜的柴犬
                                    (主体)，在赛博朋克城市的街道上 (环境)，下着霓虹色的雨 (细节)，电影级光影 (光影)，3D 渲染/虚幻引擎5 (风格)。</span>
                            </li>
                            <li><strong>语言选择：</strong>虽然模型支持中文，但在要求复杂画面、精细细节时，使用<strong>英文提示词</strong>通常能获得更精准、更高质量的生成结果。
                            </li>
                        </ul>

                        <p><strong>3. 垫图与重绘 (图生图)</strong></p>
                        <ul style="margin-bottom: 12px; padding-left: 20px;">
                            <li><strong>参考图作用：</strong>在左侧上传图片后，AI 会参考原图的构图、色彩和轮廓。你可以上传最多 10 张图片作为灵感参考。</li>
                            <li><strong>局部修改：</strong>在生成的图片上点击"重绘"，输入你想要修改的细节（例如："把背景换成雪山"），AI 会在保留原图主体的基础上尝试调整。</li>
                            <li><strong>注意事项：</strong>重绘并不是真正意义的重绘，只是起到一个把生成的图片重新发送至模型进行处理的效果，省去了你保存后重传的步骤。</li>
                        </ul>

                        <p><strong>4. 性能与限制</strong></p>

                                错误提示，说明请求过于频繁。建议适当降低"连发数量"，或稍等片刻再试。</li>
